Reading the rows
  • Row 1 — instant switch: the selected preset matches the kept previous version, so no re-run is offered; one click restores it from the cache.
  • Row 2 — bigger than the original: “ship what was asked” stops at the original's size; the previous version stays and the row says why.
  • Row 3 — failed run: an explicit button press never fails silently; the delivered file is untouched and still shown.
  • Row 4 — missing original: checked before running, reported per row, the rest of the batch unaffected.
